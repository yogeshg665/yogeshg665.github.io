# Yogesh Gupta Gudipati - Portfolio

A 3D, single-page portfolio built with React, Vite, TypeScript, three.js
(react-three-fiber), Tailwind CSS v4, and Framer Motion.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- 3D scenes mount only when scrolled into view and are disabled on mobile and
  for users who prefer reduced motion (a static gradient is shown instead).
- Content lives in `src/data/profile.ts`.
